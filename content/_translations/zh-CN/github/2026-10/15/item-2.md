Claude Code 被描述为一款运行在终端中的智能体式编程工具。据该条目介绍，它能理解用户的代码库，并通过自然语言命令驱动，而非依赖图形界面。

条目列出了它承担的具体日常任务：执行常规编程工作、解释复杂代码以及处理 git 工作流。这些是来源提供的具体机制，加上该工具位于终端这一部署方式。来源未包含定价、支持的平台、模型版本或性能测量数据，因此这份材料不足以支持与其他编程智能体的对比。
