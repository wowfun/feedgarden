## 正文提炼

Polyend 已在 GitHub 上发布原始 Tracker、Tracker+ 和 Tracker Mini 的固件源代码，并同步推出 Tracker Community Edition 1.0，带来大量新功能与改进。用户可将固件安装到三款乐器中的任意一款，自行修改并分享自己的版本；内置的恢复系统可防止有缺陷的构建导致设备变砖。运行自定义固件时损坏的硬件不在标准保修范围内，但可通过官方的保修外维修服务进行修复。Community Edition 1.0 支持从 SD 卡流式读取长采样（包括在原始 Tracker 上），为每一步新增专用的时序与力度字段，同时保留两个步进 FX 插槽，并引入新的 Chance 条件。采样编辑器可加载六种效果与生成器，插件 SDK 支持构建、分享与销售插件。Tracker+ 与 Tracker Mini 新增 CHIP 与 DIRT 两款合成器以及合成器引擎 SDK；三款机型均获得 wavetable 包络与 LFO、更快的工程加载与保存以及更精确的 MIDI 时钟同步。用户还可在浏览器中设计自定义 Tracker 主题与字体。CEO Piotr Raczyński 将此次发布描述为对非官方 Tracker 改装的支持，以及让设备所有者构建全新乐器或改变某一功能的途径。此举发生在社区对闭源固件进行逆向工程并出现替代固件之后。
