breakaway 起初是作者为自己和编码智能体做的一块任务板：智能体认领工作，人负责合并。此后它发展成作者所称的“永不下班的工程部门”，覆盖从想法到生产运行的全过程。其分工是：智能体负责认领、构建、诊断和提议，人负责合并、部署、批准和启动智能体；任何东西都不会仅凭智能体的一句话就合并或部署。

规划：写下一个粗略想法，智能体会把它整理成规格说明和任务；或者用 Kickoff 从零启动项目，由智能体提出直白的问题、建立私有仓库，随后用户合并其计划，首批任务即可就绪。任务具有领域、优先级和时间跨度（现在、接下来、以后），还可以相互依赖，并跨仓库生效。构建：认领是原子操作，两个智能体不会做同一件事；Claude Code 云端智能体可从任务板启动，输出实时显示在任务上，本地会话则通过 CLI、MCP 服务器或 Claude Code 插件接入。点击 Chase 会在你设定的上限内为每个就绪任务启动智能体；当拉取请求冲突或检查失败时会派出修复智能体；同时运行的智能体在动文件前会先确认、商定先后顺序，必要时召开 huddle。

交付与运维：部署流程负责部署、晋级和回滚，每一步都由人启动。2.0 版本新增 Architect：用只读令牌连接 Cloudflare 后，任务板显示每个环境运行的内容、健康状况以及相对预算的预估成本；智能体通过拉取请求提出基础设施变更，计划中说明改动内容、成本和是否可撤销，你在手机上点击批准，由你自己仓库中的工作流执行。Envelopes 是一次批准的限制，例如 2 到 10 个实例或每天 3 次重启，任务板在其中扩缩容和重启，事后向你报告。事故会在拥有故障组件的仓库中作为任务打开，runbook 可立即启动智能体诊断并提出修复；只有生产事故才会推送到你的手机。Routines 按计划（每周变更日志、每夜依赖检查）或事件（拉取请求合并、工作流失败、议题开启、计划失败、预算超支）运行智能体，需要人时通知收件箱。

据称任务板不持有你基础设施的写凭证，运行在你自己的 Cloudflare 账户上，没有托管版本、账号或遥测，安装只需把一段提示词粘贴进 Claude Code。授权方面：自 2.0 起采用 PolyForm Noncommercial License 1.0.0，个人与非商业用途免费，涵盖个人、爱好者、慈善机构、学校和公共机构；商业用途为例外，对工人合作社以及数字权利与隐私团体免费逐案授予，但绝不授予风险投资支持的公司；没有价格、没有付费档位，源代码公开。
