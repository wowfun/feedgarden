一位开发者表示自己一直在使用 Google 的 Antigravity IDE，但后来在该 IDE 中使用的“Opus 5.5”比 Gemini 系列模型还多。他们打算离开 Antigravity IDE 转向 Claude，主要目的是获得更好的 Claude 模型配额，其工作约 90% 是编程。

他们提出了三个具体问题：20 美元套餐是否包含 Opus 5.5；Claude 桌面应用是否提供 IDE 功能；以及 Claude 与 Claude Code 之间的区别。由于不喜欢命令行界面，他们打算使用桌面应用，并想知道它是否具备 CLI 的全部能力。此外还希望了解从 Antigravity 迁移过来的用户的优缺点与经验建议。
