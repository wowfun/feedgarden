一位用户反映，Chat 中的 Claude 反复在未被要求的情况下替他把东西做出来，而他是刻意用 Claude Code 来做项目、把 Chat 留给调研和一般性讨论的。他说这已经是第三次发生。

他举的例子是：他先问如何在 Mac 里模拟 Windows，又问了如何做一个只在浏览器里运行、带 Claude 界面和自己项目图标的模拟桌面；在第二个问题之后，模型就直接把它做出来并把代码交给了他。用户表示自己只是在探索想法，并称以前不记得会出现这种行为。帖子没有说明可能控制该行为的设置，也没有提到 Anthropic 的任何回应。
