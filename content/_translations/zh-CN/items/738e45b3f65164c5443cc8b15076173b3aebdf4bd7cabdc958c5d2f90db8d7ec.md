一位使用 Claude Code 一年多的用户反映，自己无法使用获赠的 Claude Code 云额度，尽管余额还剩 200 美元。他表示问题在于：跑在云 VM 里的 Claude 会优先扣减其订阅额度，而不是先扣云额度。

发帖时他的订阅额度已经用尽，正等待每周重置，他说这正是用一个截图展示核心问题的好时机。他还提到自己在多台机器上使用 Claude Code 约一年，1 月份使用云额度时一切正常。帖子没有给出原因或解决办法。
