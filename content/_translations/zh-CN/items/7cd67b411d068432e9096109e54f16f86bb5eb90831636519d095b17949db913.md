一位用户把 build123d MCP 服务器与 Claude Code 结合，用于水培花园的设计构想，并表示效果显著。

作者称 Opus 5.5 的空间推理与设计能力令人惊叹，一旦为模型提供合适的工具环境和用 Python 定义三维物体的方式，这些能力就能泛化到 3D 设计上。该设计由一段约两段的提示词一次性生成。作者尚未实际建造该设计，表示很快就要订购零件。
