一位开发者发布了一个 Claude 插件，用户只需一句话即可查询巴西众议院（Câmara dos Deputados）。它是为帮助从事政治学和政府关系的朋友而开发的；作者表示，该工具主要对巴西人有用，但其他人也可能感兴趣。

该插件连接众议院的开放数据接口，因此可以用自然语言检索这些数据。数据与插件均为巴西葡萄牙语，但据作者称 Claude 翻译毫无障碍，因此可以用英语提问并以英语获得回答。

安装面向 Claude Code 或 Cowork，通过两条命令添加插件市场并安装插件。作者给出的示例查询包括：询问法案 PL 2338/2023 的当前状态；对 2025 年议员津贴（cota parlamentar）支出最多的 10 位议员进行排名；把现任议员名单连同党派和州导出为电子表格文件。代码仓库托管在作者的 GitHub 账号下。
