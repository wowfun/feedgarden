一位用户表示自己无法正确安装 Claude Code 更新，因此用不了 Haiku 5.5 模型。他说应用内的更新按钮根本不工作。

从官网下载新版 Claude Code 后，Haiku 5.5 模型可以使用，但应用一旦重启，该模型就又变得不可用。他指出，此前的 Sonnet 5.5 应用更新一切正常，这让当前的问题显得格外突出。

帖子询问该怎么办。除了“应用内更新按钮”和“手动下载”这两条路径表现不同、以及模型的可用状态无法保持之外，帖子没有提供日志细节、版本号或客服回复。
