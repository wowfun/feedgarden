一位谷歌 Antigravity IDE 的用户表示，在 Antigravity 上他用 Opus 5.5 的次数反而比 Gemini 系列模型更多。他打算离开 Antigravity 转向 Claude，以获得更好的 Claude 模型配额，并提出了几个问题。

他的问题：
- 20 美元的套餐是否包含 Opus 5.5？
- Claude 桌面应用是否提供 IDE 功能？
- Claude 和 Claude Code 有什么区别？

他说自己不喜欢 CLI，会使用桌面应用作为界面，想知道是否也能获得 CLI 的全部能力。他的工作约 90% 是编程。他还希望从 Antigravity 迁移过来的用户分享经验，包括优缺点。
