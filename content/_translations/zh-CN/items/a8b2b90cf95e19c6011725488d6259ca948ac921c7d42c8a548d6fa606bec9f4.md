发帖者为 Claude Code 订阅支付 99 美元，表示自己相当满意，但作为家庭中唯一的经济来源，这笔开销不小，因此一直在寻找更便宜的替代方案。他们试用过 Muse Spark 1.3，但认为其表现太低：把额外投入的时间计算在内，它并不比 Claude 便宜，多花的时间成本远远超过订阅费用。

发帖者询问开源模型在编程上是否真的能与 Claude Code 竞争，并说互联网上充斥着对开源模型的吹捧，自己已经不再相信任何说法。在补充编辑中，他们表示自己需要一个与 Opus 相当的 Pro 级模型，因为即使 Sonnet 也经常失败，最后往往只能靠手工完成。帖中没有给出具体的对比数据或基准测试，整个问题基于发帖者自身的经验。
