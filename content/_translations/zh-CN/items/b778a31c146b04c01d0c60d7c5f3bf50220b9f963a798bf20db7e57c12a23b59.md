一位刚开始用智能体大约一周的开发者，询问他人在 Claude Code 中如何配置编排（Orchestration）。他自述大致是中级开发者：做过两年软件开发，如今在网络安全领域工作，为公司做了一个内部工具，并帮助同事用 Claude Code 节省时间。他说自己最初对氛围编程持怀疑态度，试过之后才改变看法，目前使用 5x Max 套餐。

他当前的方案是在应用内使用编排：由 Opus 负责规划，再把任务分派给运行在某款 Sonnet 模型上的子智能体。他固定设置了几类智能体：规划、审查、安全检查、后端、前端。他还提到用这种方式在做一款类似《魔灵召唤》风格的游戏，效果出乎意料地好。

他的问题偏配置而非概念：别人是否会用不同的模型分别做规划和子智能体，以及每个角色使用什么思考等级。帖子里没有给出答案或评测数据。
