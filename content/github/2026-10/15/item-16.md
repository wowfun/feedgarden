garrytan/gstack packages Garry Tan's own Claude Code setup. It contains 23 tools that the description characterizes as opinionated, meaning they encode specific working choices rather than staying neutral.

The tools are assigned roles: CEO, Designer, Eng Manager, Release Manager, Doc Engineer and QA. The pitch is that users can adopt this exact arrangement instead of assembling their own set of coding-agent configurations.
