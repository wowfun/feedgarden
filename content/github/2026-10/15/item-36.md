Ollama is a project for getting local model runs up and running quickly. The listing names the models it advertises support for: Kimi, GLM, MiniMax, DeepSeek, gpt-oss, Qwen and Gemma.

The value proposition is convenience: instead of assembling a serving stack, users can start these models with the project's tooling. The source does not state supported operating systems, hardware requirements, quantisation options or performance figures, so anyone planning a deployment should verify those details from the repository itself before committing to a setup.
