public-apis is described as a collective list of free APIs.

It serves as a reference index that developers can consult when looking for free application programming interfaces to build against. The listing does not indicate how many APIs are included, how entries are verified, how often they are updated, or the terms under which each API is free, so users should validate an individual API's availability and licence before depending on it.
