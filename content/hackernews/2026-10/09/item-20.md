## Article

Pocketty is an iPhone and iPad SSH terminal built around herdr, a tool for managing coding-agent sessions. The premise is that you should not have to sit at your desk to know when an agent needs you: the app shows every agent and pane on a host, labels each one working, needs you, or done, and notifies you when a pane becomes blocked or finishes.

The client connects straight to your machine over SSH, per the author, with no server in the middle. Tunnels and key handling use the Secure Enclave and Face ID, and the demo shows a link like "pane w1:p1 on studio" over Tailscale. Notification alerts are generated by a daemon on the host, sealed with the phone's key using HPKE &#40;X25519 plus ChaCha20&#41;, relayed through a Cloudflare Worker that forwards sealed bytes to Apple Push Notification service, and finally opened on the phone. The relay, the Worker and Apple therefore never see pane text or terminal output; the relay stores nothing. Notifications are optional.

The terminal itself is a real one: the on-screen keyboard exposes Return, Esc, Ctrl and arrow keys, so agents receive genuine keystrokes. A text mode sends a whole message at once, and dictation and images are supported. Swiping in from the edge shows the diff for the current agent turn; a daemon snapshots the worktree whenever an agent starts work, so you can inspect only that turn, the whole session, or everything uncommitted &#40;similar to git diff&#41;, and the last two views require the daemon. There is a file browser with syntax coloring in 20 schemes, and when a pane opens a port the app offers a localhost preview served through the SSH connection with no separate tunnel. Pocketty reads agent state from herdr without editing agent config files. Without herdr, you still get a normal login shell, or tmux and zellij with a startup command.

The listed price is &#36;99 as a launch price, down from &#36;129, after a 14-day free trial. The page says the app works with every agent herdr knows; the submission does not include independent measurements or third-party security review.

## HN discussion

Based on 9 selected comments and replies.

Commenters mostly compared Pocketty with alternatives rather than evaluating its security claims. One said they had looked for something similar and found herdr-web-ui, describing it as free, self-hosted, installable as a PWA with web push support and under heavy development. Another recommended Heeler as free and open source for the herdr and iOS combination, saying it had replaced Blink Shell on their phone over a few weeks; a reply in the same thread seconded that recommendation. One commenter, who had run tailscale to a laptop with a TUI, said the setup worked for a while but they eventually did not want notifications that agents were not working. The submitter replied that the tool is now mostly for walks, errands or sudden ideas, and that trusting the notification pipeline removes the need to babysit agents. One commenter asked how you can tell whether an agent is thinking rather than blocked; the submitter answered that the app colors the agent icon yellow for working, green for done, red for blocked and grey for idle, and that the tab list can be filtered by state. Another framed the broader pattern as turning an agent chat push into a feed pull, with agents reaching out to the user rather than the reverse. These are individual opinions from a small sample.
