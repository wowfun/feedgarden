## Article

Microsoft is rolling out a Windows 11 preview update, KB5127936, cumulative for versions 26H2 and 25H2, that addresses a long-standing complaint about the right-click context menu. The update adds a “customize menu” button letting users toggle built-in commands such as Send To and Create Shortcut, rearrange what appears on the main menu, and choose which third-party extensions show in the main or submenu. Previously, familiar commands were hidden behind a top row of icons and an extra “Show more options” click. The preview also introduces Cloud Rebuild, a recovery option that reinstalls Windows 11 directly from the cloud—pulling the OS image and needed drivers from Windows Update—even when the existing installation will not boot. No custom recovery image or external media is required. Microsoft notes it behaves more like a fresh install than a repair: existing applications and files are not preserved, though system drives can be sanitized beforehand for security. The announcement coincides with Microsoft’s quarterly financial report, which showed a continued decline in revenue from Windows licenses for new PCs. A fuller list of changes, including Xbox mode and settings updates, is in Microsoft’s official release announcement. The update is a gradual rollout before general availability.
