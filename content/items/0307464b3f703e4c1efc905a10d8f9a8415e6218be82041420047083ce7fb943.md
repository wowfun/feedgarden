A long-time ChatGPT user asks whether they are prompting incorrectly or whether output quality has genuinely declined, describing a fantasy NBA draft task that repeatedly failed on basics. The user asked the model to check a draft board, identify which players were still available, research breakout candidates and compute their value under a specific league scoring system.

According to the poster, the model kept recommending players who had already been selected. The user escalated by sending screenshots of the current draft board with every round request, but in the final round it still named Giannis, Kawhi and Tatum, which the user says are clear first- or second-round picks that had definitely already been taken.

The user says the most frustrating part was correction: they would explain exactly what they needed, the model would agree, and then repeat the same class of mistake a few messages later. They stress they are not expecting accurate predictions, only instruction following, context tracking and basic fact checking before recommendations.

The poster says the tool used to perform such tasks reliably and now feels far weaker, to the point where they question the value of using it for simple work. They ask for practical recommendations, whether they are using ChatGPT wrong, and whether others have seen similar recent behaviour. Note this is one user's anecdotal account with no independent verification.
