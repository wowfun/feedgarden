A user praises herdr, a terminal tool they had wanted for a long time, saying they now use it for personal projects and for work, which takes up about 80% of their time. They run it on WSL through Windows Terminal alongside Codex, Claude, and another agent.

Reasons they like it:
- It is lightweight, using near-zero RAM or CPU, with a minimal base UI.
- It is not a bloated Electron app; they uninstalled a comparison tool called orca within two hours because it was too opinionated about worktrees.
- It is highly customizable, from keybinds to custom plugins. One of their plugins renders agent responses in markdown in a modal, which helped with mermaid diagrams.
- They highlight ttt, a lightweight VS Code clone, as an important companion plugin.
- They say they never need to leave the terminal, even without using pane-to-pane agent coordination or remote features.

They ask the team to keep the product as it is and say they would build their own clone if it departed from this minimalist promise.
