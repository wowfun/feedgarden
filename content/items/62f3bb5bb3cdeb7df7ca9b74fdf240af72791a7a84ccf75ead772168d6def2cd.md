A developer built a personal portfolio as an interactive relativistic black-hole infall simulation at iamkhalid.xyz, replacing a conventional card-based resume with a continuous journey from deep space into a supermassive black hole, past the event horizon, and into a 4D tesseract. It is built with Next.js 16, Three.js/WebGL2, raw GLSL, and Web Audio, and is free to explore in a modern browser.

The reported contributions from Claude span several areas: translating Schwarzschild metric formulas and gravitational lensing equations into optimized GLSL raymarching shaders, with blackbody color lookups and float64 precision clamping so light bending renders cleanly; architecting an additive synth engine in the Web Audio API that generates custom periodic waves for an organ drone and computes Doppler and blueshift filters tied to infall velocity, with no audio files; designing an external mutable state store outside the React lifecycle so Three.js holds a steady 60 FPS while scrolling without triggering heavy re-renders; and structuring a stardust portrait engine that sizes particle counts from human body elemental mass percentages &#40;65 percent oxygen, 18.5 percent carbon, and so on&#41; and color-codes them by cosmic origin.

Interactive details include a preloader that scrubs through a star core collapse from helium to iron ash, click-and-drag pitch and yaw around the accretion disk, a small 12-module ship above the disk that plays transmissions when clicked, optional procedural audio with a 1.25-second tick where one tick equals one day on Earth at Miller depth, a desktop navigation bar that doubles as a logarithmic Schwarzschild radius gauge from about 22 rs down toward zero, project entries rendered as 400 to 700 nm emission spectra instead of screenshots, and a hidden retro command line behind the backtick key with a separate command palette shortcut.
