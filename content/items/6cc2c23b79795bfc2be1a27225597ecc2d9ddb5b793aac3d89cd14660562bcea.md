A Reddit user &#40;/u/jeffsale&#41; describes building a 3D hyperglyph-based visualization tool called GlyphViz, largely written with Claude Code inside VS Code, predominantly using Opus 5 High, over a period of a few months. The stated goal was a tool the author had wanted for a long time, and they judge that Claude did a good job on it.

The LLM visualization angle reportedly came from asking Claude what it would do with GlyphViz to address public fears that AI would be dangerous within a decade, and to generally improve the world. One suggested idea was to visualize models such as GPT-2 and Gemma-2-2B-it so people could understand them better and worry less. The result includes a video of the GPT-2 visualization, produced by Claude.

The author points to an examples gallery on iluvdata.org containing the GPT-2 "AI observatory" visualization and dozens of others, available through a desktop tool and a browser-based web version; it also runs in VR on a Quest 3. An accompanying image is described as a visualization of the 222 Claude Code sessions used to build GlyphViz. Code is provided so others can generate similar visualizations for their own VS Code projects, and a Claude GlyphViz skill is offered to drive the tool with simple prompts. A GlyphViz YouTube channel hosts more videos.

The post supplies no benchmarks, accuracy claims, or independent evaluation of whether such visualizations actually change how people understand or trust models. All specifics — session count, model names, deployment targets — are the author's own account.
