A long-time Claude Code user reports being unable to spend Claude Code cloud credits they were given, even though &#36;200 of that balance remains. They say the problem is that Claude running in the cloud VM draws on their subscription allowance ahead of the cloud credits.

At the time of posting their subscription credits were exhausted and they were waiting for the weekly reset, which they say is an ideal moment to capture the core problem in a screenshot. They note they have used Claude Code on a number of machines for about a year, and that the cloud credits worked fine when they used them in January. No root cause or fix is stated in the post.
