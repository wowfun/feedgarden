A Reddit user has released Clawd View, a free, open-source plugin for Claude Code that replaces the raw stream of tool calls with a plainer progress display. The author says they liked Claude Code but found watching it work "like reading a wall of tool calls I couldn't follow."

What the plugin shows:
- A live checklist above the prompt, with progress bars
- A prompt when Claude needs approval, plus an explicit signal when it is stuck
- At-a-glance usage limits, context and cost
- Clawd, a pixel mascot that acts out each step and "throws a party" when the job finishes

Additional features include chatting with Clawd, a mini game to play while waiting, and a music mode limited to Mac. Running /clawd-view off restores the full tool output at any time. The plugin is said to work in the terminal on Mac, Linux and Windows, and in the Claude desktop app. Installation is done inside Claude Code, one command at a time: add the marketplace thedepegger/clawd-view, install clawd-view@clawd-view, then run /reload-plugins. The code is on GitHub. The author notes it is their first plugin and is asking for feedback on what else it should display.
