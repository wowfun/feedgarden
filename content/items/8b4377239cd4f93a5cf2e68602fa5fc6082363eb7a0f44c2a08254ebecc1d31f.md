A developer released a Claude plugin that lets users query Brazil's Chamber of Deputies &#40;the Camara dos Deputados&#41; with a single sentence. It was built to help friends working in political science and government relations, and the author says it is mostly of interest to Brazilians but may interest others.

The plugin connects to the chamber's open data endpoint, so the data can be searched in plain language. The data and the plugin are in Brazilian Portuguese, but the author says Claude translates without trouble, so questions can be asked in English and answers returned in English.

Installation is described for Claude Code or Cowork through two commands that add the marketplace and install the plugin. Example queries given by the author are: asking the current status of a bill, PL 2338/2023; ranking the 10 deputies who spent the most from their parliamentary allowance &#40;cota parlamentar&#41; in 2025; and exporting the list of sitting deputies with party and state to a spreadsheet file. The repository is hosted on GitHub under the author's account.
