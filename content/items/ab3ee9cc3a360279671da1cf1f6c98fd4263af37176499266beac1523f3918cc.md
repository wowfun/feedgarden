A user criticizes the Projects beta redesign, arguing it assumes use for large coding projects with many collaborators and many instances running simultaneously. The described changes include conversations, now framed as threads within one long session, being divided into "resolved", "idle" and "waiting on decisions, reviews and permission requests", along with new ways to hook up routines and repositories.

The author says they do only a little vibe-coding and have never used Projects for that purpose, instead using it for travel planning, creative work and home improvement. Their complaint is that personal projects are now stranded in a user interface that clearly was not designed for them, when other new features could have served a wider range of Projects users. The post acknowledges software development is the highest-priority customer base for Claude.
