A developer built and released a drop-in replacement for GitHub Pages. It offers the same features as GitHub Pages but adds a private dashboard on top for viewing logs and statistics for the page. Because it is a regular webserver, the author says webservices, websockets and databases can be added on top.

Deployment is described as changing two lines in an existing workflow, and an assistant is also available to guide users through the process. Custom domains are possible but not yet automated, and the author asks interested users to send a direct message if they need one.

The project was built with Opus 5.5 at the xhigh setting in about half an hour as a thin layer over the existing hosting capabilities and APIs of GenHTTP Lambda. The author estimates it took 200k tokens to generate, with another 200k spent on testing and bug fixes, and calls that result impressive.
