A user wants to train a model that thinks, acts and talks like them. They have downloaded their entire internet history, including Reddit posts, emails and chats, and intend to keep the work as local as possible because the corpus contains a lot of personal information. Available hardware is a 2080 Ti with 11 GB and a 5070 Ti with 16 GB.

Their current attempt is a qLoRA pass on a Qwen3.5-9B base. They report that A/B tests still make it fairly clear the model is not them, and they ask what the best method is today. They also link a document describing the path already taken.

The item is a request for advice and shares no results beyond that negative outcome, so it provides no evidence about which training approaches work better.
