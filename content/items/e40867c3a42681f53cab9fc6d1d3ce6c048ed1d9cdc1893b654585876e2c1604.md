The poster has used the ECC Report workflow for a while but is unsure whether it is still necessary. After buying a first MacBook, they loaded a second account with a Claude Pro subscription to finish work tasks, set basic rules in a Claude.md file and ran a project without ECC. They report that on the Mac, standard rules plus artifacts load at about 20k context, while their Max plan burns roughly 80k on load, which they attribute mostly to ECC, built-in tools and artifacts.

After five days on the Mac, the poster wants a way to validate whether continuing with ECC provides any benefit on the 5.5 models. They describe feeling stuck between keeping ECC, letting Claude run on its own with their rules and specific guidelines, or finding a repository focused on helping Claude with project planning and development guidelines.

Two side questions are raised: how to link GitHub across a Windows machine and the new Mac, and whether anyone can point them in the right direction on the broader decision.
