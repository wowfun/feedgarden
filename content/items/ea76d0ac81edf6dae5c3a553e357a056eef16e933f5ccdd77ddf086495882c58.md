The author describes how they start their 5-hour GPT Plus usage window as soon as they sit down at the PC, so that it resets earlier in the day. In practice, they ask a simple math problem while at work to start the 5-hour clock.

On this occasion they did not realize the model was set to Astra High. They asked "What is 1+1", and report that it answered in about 5 seconds while consuming 16% of the 5-hour window.

The author's only stated judgment is that this consumption is "insane." The post provides no further data about the model, the window, or how the figure was measured.
