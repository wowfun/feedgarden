A user who installed Strata together with Qwen3.8-next-flash on a personal PC reported being impressed by the model but unable to find any setting that enables or adds tool calling, so the assistant could read, write and execute files locally. They asked how this is done in Strata.

In an update, the same user said that following suggestions they moved to a harness instead of configuring tool use inside the Strata web UI. They ended up liking the DeepSeek harness a lot and reported that it is working great. No technical explanation of Strata's tool-calling configuration was supplied in the thread as captured here.

The item is notable mainly as a user-experience data point: tool execution for local file operations was not discoverable in that web interface, while an external harness solved the need.
