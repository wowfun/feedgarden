## 1. Claude 发现一种带有类 CRISPR 重复序列的新型酶系统

Anthropic 介绍了其生命科学研究团队与实验室，使用 Claude 探索 DNA 数据集并大规模提出假设。在一项早期研究中，仅给出高层提示后，Claude 自主发现了一种与一组非编码 DNA 重复序列相关的新型酶系统，其基于一种巨型噬菌体中的逆转录酶。该系统功能尚不明确；作者称 Claude 似乎是首个注意到该系统关键特征的主体。CRISPR 先驱张锋称这是 AI 智能体助力生物学发现的一个令人振奋的例子。

## 2. 编码会话更长、上下文更多，Claude Opus 5.5 为此而打造

Anthropic 称，对于按 token 计费的典型工作负载，Claude Opus 5.5 的运行成本估计比 Opus 5 低约 40%，其输入与输出 token 价格下调 20%，缓存 token 读取价格下调 60%。公司报告称，2026 年 3 月至 9 月间，Claude Code 会话每个提示的工作时长增加 3.3 倍，中断减少 68%，每次请求的上下文增加 2.6 倍，未命中缓存的输入减少超过 50%。

## 3. Claude Tag 现支持在频道中使用个人连接器

将 Claude 加入 Slack 频道的 Claude Tag（测试版）现在可以在用户于频道内发起请求时使用其个人连接器，因此日历、云盘或 CRM 账号等个人工具无需向频道共享即可访问。用户可以在回复发布前逐条审核，也可使用自动模式并对敏感内容进行筛查；企业版管理员将能够要求所有人必须审核。定时例程和 Claude 自主发起的操作仍使用管理员为频道配置的连接器。现已在团队版推出，企业版随后跟进。

[原文](https://claude.com/blog/claude-tag-now-supports-personal-connectors-in-channels) · 2026-09-23
