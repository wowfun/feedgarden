## 1. Claude discovers a novel enzyme system with CRISPR-like repeats

Anthropic introduced a life sciences research group and lab using Claude to explore DNA datasets and generate hypotheses. In an early program, Claude, given only a high-level prompt, autonomously found a novel enzyme system associated with an array of non-coding DNA repeats, based on a reverse transcriptase in a jumbo phage. Its function is unknown; the authors say Claude appears to be the first to notice the system's defining features. CRISPR pioneer Feng Zhang called it an exciting example of AI agents contributing to biological discovery.

[Original](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) · 2026-09-23

## 2. Coding sessions are longer and use more context. Claude Opus 5.5 is built with that in mind.

Anthropic says Claude Opus 5.5 is estimated to cost about 40% less to run than Opus 5 for typical token-billed workloads, citing 20% lower input and output token prices and a 60% lower cached-token read price. The company reports that from March to September 2026, Claude Code sessions saw 3.3x longer work per prompt, 68% fewer interruptions, and 2.6x more context per request, with cache-missing input down over 50%.

[Original](https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context) · 2026-09-23

## 3. Claude Tag now supports personal connectors in channels

Claude Tag &#40;beta&#41;, which adds Claude to a Slack channel, can now use a user's own connectors for requests they make in that channel, so personal tools like calendar, drive or CRM accounts are reachable without being shared with the channel. Users can review each response before it posts or use auto mode with screening for sensitive content; Enterprise admins will be able to require review. Scheduled routines and actions Claude starts on its own still use the channel's admin-attached connectors. Rolling out now on Team plans, with Enterprise to follow.

[Original](https://claude.com/blog/claude-tag-now-supports-personal-connectors-in-channels) · 2026-09-23
