## 1. Giving companies more control over their AI agents, with NVIDIA

Anthropic says it collaborated with NVIDIA, which announced the Open Agent Safety Platform, an open software platform and reference system design for AI security. Claude Managed Agents keeps agent credentials in a separate vault, runs the agent loop apart from the sandbox, and provides audit trails; NVIDIA's open source OpenShell runtime governs and logs agent actions, blocking unless a rule allows, with a policy prover to confirm reachable resources. The post cites Notion, Rakuten and Asana as users.
