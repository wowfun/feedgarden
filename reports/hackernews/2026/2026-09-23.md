## 37. Show HN: Treepeat – Code similarity detection using Tree-sitter

The author presents Treepeat, a proof-of-concept tool that finds similarities in a codebase. It detects duplicate code blocks meaningful to the language, such as classes and functions, not just lines; finds near-duplicates by ignoring whitespace, strings and high-level AST nodes; and finds structurally similar code by anonymizing identifiers and constants. Only a few languages are supported so far; pull requests are welcome. Listed languages: astro, bash, css, go, html, javascript, lua, markdown, python, sql, typescript, java, kotlin, rust, yaml.
