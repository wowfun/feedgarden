## 38. Show HN: Air-gapped file encryption as self-decrypting HTML page

The author presents an air-gapped file encryption tool packaged as a single, self-decrypting HTML page. Stated goals: no installation beyond a web browser, a single file that self-decrypts with no network, and full auditability. The third is supported by roughly reproducible builds with embedded OpenPGP signatures, with reproducibility depending on the OS at present. The HTML structure is manipulated so decryption works without breaking the PGP signature, and decryption can even be done with bare openssl. The source is freely available.

## 49. Show HN: AgentRun: DSL to turn agents into workflows

The author open sourced AgentRun, the DSL used by their grep.ai harness to turn repeatable parts of agent work into workflows. It can combine tool calls, code, Jev-powered decisions for routing and evidence screening, and agents for steps needing more investigation. The harness uses agent traces and retro notes to identify parts that can become a workflow, aiming to make work easier to understand and avoid full agent loops where unnecessary; the DSL and examples are on GitHub, with a scripted demo runnable without API keys and use as a Pi extension.
