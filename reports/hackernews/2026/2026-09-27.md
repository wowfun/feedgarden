## 4. Show HN: Reladraw – A diagram language where you decide where to place things

The author built Reladraw because existing diagram options each fall short: auto-placement languages like Mermaid or Graphviz don't let you decide how a diagram looks, while tools like Draw.io are powerful but time consuming and inefficient for agents to manipulate. Reladraw aims to offer both, letting you define a diagram in a diagram language while retaining strong control over its appearance, and to work for humans and agents. The GitHub link has a no-install playground, npm install instructions and a skill for Claude or other agents.
